# Demo script — TIGERIS · Sovereign Intelligence OS

About 25 minutes, then questions. It follows the in-app **Guide**: the button at the bottom corner of every screen shows the same ten steps. Switch roles from the menu at the top right. Everything shown is public or synthetic data about fictional institutions.

## Before you start (5 minutes before)
1. Open the app and sign in as **Analyst · GCC Sovereign Fund A** (demo entry; the code is shown on screen).
2. Header menu → **Reset demo** (press twice). This takes about 30 seconds and gives a clean state.
3. Check the header badges: **Foreign models off · local model**, **Demonstration Mode**.
4. Optional warm-up: on case GSF-2026-0001, open **Agents** and press **Run analysis** once. Later runs reuse its cached model text, so the live run takes seconds.
5. Close any other browser tabs. The laptop needs no internet connection.

## If something goes wrong
- **Something looks off:** Reset demo (header menu), then follow the Guide from the step you were on.
- **The agent run is slow:** the steps appear as they finish. Talk through the challenge round in the meantime, or use the run from the warm-up (choose it under Earlier runs).
- **A blank map:** reload the page. The map is fully offline.
- **A question about live foreign models:** they are blocked by design. Show the blocked attempt in Governance → AI models → recent blocked calls.

## What not to claim
- No live feeds: the movement stream is simulated and labelled.
- No real institutions or people.
- No forecasts: scenarios are outputs of stated assumptions.
- Nothing executes outside TIGERIS: decisions create handoff tasks only.
